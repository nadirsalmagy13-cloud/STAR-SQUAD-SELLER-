# 🎬 Plataforma de Venda de Vídeos — Esquadrão de Estrelas

Este projeto é um site criado para vender vídeos digitais de forma simples e rápida.  
O cliente escolhe a categoria, vê a prévia e compra pelo PayPal.

---

## 🚀 Funcionalidades
- 17 categorias de vídeos
- Pré-visualização automática (autoplay)
- Pagamento via PayPal
- Entrega pelo Telegram
- Layout responsivo para telemóvel
- Design dark premium

---

## 🧩 Como funciona
1. O cliente entra no site  
2. Escolhe uma categoria  
3. Assiste à prévia  
4. Clica em **Comprar**  
5. Paga pelo PayPal  
6. Recebe o vídeo pelo Telegram

---

## 🛠️ Tecnologias usadas
- HTML  
- CSS  
- JavaScript  
- GitHub Pages  
- PayPal Checkout  
- Google Drive / Dropbox

---

## 📂 Como editar os vídeos
1. Envie o vídeo para Google Drive  
2. Gere um link direto  
3. Cole o link no iframe da categoria  
4. Salve e publique
